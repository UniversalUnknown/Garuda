# Networking and Python Scripts

This directory contains Python scripts organized by category:

## Directory Structure

### wifi/
WiFi-related Python scripts:
- wifi.py - Basic WiFi functionality
- wifi2.py - Enhanced WiFi features
- wifi3.py - Advanced WiFi monitoring tool

### web/
Web-related Python scripts:
- WebScrap.py - Web scraping utilities
- test.py - Testing utilities

### Root Directory
General Python utilities:
- ds.py - Data structure implementations
- ds3.py - Additional data structures
- pipe.py - Pipeline utilities

## Usage
Each script can be run independently using Python 3:
```bash
python3 script_name.py
```
